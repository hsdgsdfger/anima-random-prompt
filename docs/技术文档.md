# anima 随机提示词 · 技术文档（v0.11.17）

> 适用仓库：`hsdgsdfger/anima-random-prompt`
> 节点版本：`0.11.17`（`__init__.py` 内 `__version__`）
> 文档日期：2026-11-16
> 适用范围：本文只描述当前仓库这一版的真实实现；未实现的能力单独列在「已知限制」。

## 1. 定位与边界

这是一个 **ComfyUI 自定义节点**，做两件事：

1. 在节点里按档位随机生成**一整段可用的正向提示词**（附带负向提示词与分级报告）；
2. 提供一个网页工作台，让人可以**手选词条 / 浏览 1800 套模板**，手选结果实时写回节点。

边界：

- 完全独立，**不读取、不修改 Anima Wardrobe V6 的任何文件**。
- 不依赖第三方 Python 包，只用 ComfyUI 自带的 `server.PromptServer` 与标准库。
- 数据全部静态随仓库分发（`data/*.json`），运行时不联网。
- 仓库**不提供 Release 包**，安装方式只有 `git clone` / 升级只有 `git pull`。

## 2. 安装与目录结构

### 2.1 安装

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/hsdgsdfger/anima-random-prompt.git Comfyui-Prompt-Forge
```

重启 ComfyUI 后节点注册到 `AnimaDecouple / Prompt Forge` 分组。

ComfyUI 以 `custom_nodes/<目录>/__init__.py` 作为插件入口，因此仓库**根目录就是插件包**：`__init__.py` 里的 `from .engine import ...` 在同目录解析，`data/` 与 `web/` 用相对路径定位。

### 2.2 目录结构

```
Comfyui-Prompt-Forge/
├── __init__.py          节点定义 + 4 条 HTTP 路由
├── engine.py            随机引擎（槽位抽取 / 分级 / 覆盖文本 / 负面词）
├── scenes.py            场景拼装器（动作姿态、单人双人分档、兜底）
├── data/
│   ├── tags.json        25 分类 / 2956 条词条（含中文、分级、meta 标记）
│   ├── scenes.json      45 个场景包 + 互斥标记
│   └── templates_ui.json 1800 套模板精简版（工作台用）
├── web/
│   ├── prompt_forge_v5.js        扩展入口：注册按钮、把 UI 挂到节点
│   ├── prompt_forge_core_v5.js   工作台全部 UI 逻辑（无 ComfyUI 依赖，可独立运行）
│   └── preview.html              独立预览页（不装节点也能看界面）
├── docs/技术文档.md
└── README.md
```

## 3. 节点接口

### 3.1 基本信息

| 项 | 值 |
| --- | --- |
| 类名 | `PromptForgeRandom` |
| 显示名 | `Prompt Forge 随机提示词（中文）` |
| 分类 | `AnimaDecouple/Prompt Forge` |
| 输出 | `positive` / `negative` / `level` / `report`，均为 `STRING` |
| 前端目录 | `WEB_DIRECTORY = "./web"` |
| 版本 | `__version__ = "0.11.16"` |

### 3.2 必填参数（12 个）

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `level` | 下拉 | `sfw · 全年龄` | 档位：sfw / suggestive / explicit / hardcore / extreme / any |
| `seed` | INT | `-1` | `-1` 每次重抽；`>=0` 可复现 |
| `tag_cap` | INT | `0` | 总标签上限，`0` = 自动（全年龄 26 / 成人 30） |
| `base_prob` | FLOAT | `0.65` | 可选槽位的基准出现概率 |
| `slot_weights` | STRING | 空 | 槽位加权 JSON，如 `{"clothing":1.5,"props":0}`，0 = 关掉该槽位 |
| `role_mode` | 下拉 | `不指定` | 不指定 / 随机 / 指定 |
| `role_name` | STRING | 空 | `role_mode=指定` 时的角色名或 danbooru tag 片段 |
| `role_works` | STRING | 空 | 按作品限定随机角色，`|` 分隔 |
| `quality_prefix` | STRING | `masterpiece, best quality` | 质量前缀文本 |
| `artist_on` | BOOLEAN | `false` | 是否随机带一个画师标签 |
| `negative_on` | BOOLEAN | `true` | 是否同时输出负面提示词 |
| `extra_body` | STRING | 空 | 手写补充，拼在正向末尾 |

### 3.3 可选参数（4 个）

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `quality_on` | BOOLEAN | `true` | 是否加质量前缀 |
| `scene_mode` | 下拉 | `场景成套 · 现实逻辑` | 场景成套 = 环境/服装/道具绑定在同一场景；自由随机 = 全库各抽各的 |
| `template_override` | STRING | 空 | **非空时直接作为正向提示词，跳过随机**；工作台勾选/套用即写这里 |
| `random_each_run` | BOOLEAN | `true` | 每次运行重新随机：勾上后忽略固定 `seed`，每跑一次换一份 |

> 控件顺序是契约：新增参数只能追加到末尾，否则旧工作流的 `widgets_values` 会错位。

### 3.3.1 控件中文标签

画布上的控件名由前端映射为中文（`web/prompt_forge_v6.js` 的 `LABELS`），序列化键名仍是英文，所以旧工作流与 API 不受影响：

| 键 | 中文标签 |
| --- | --- |
| `level` | 档位 |
| `seed` | 随机种子 |
| `tag_cap` | 标签上限 |
| `base_prob` | 基础概率 |
| `slot_weights` | 槽位权重（JSON） |
| `role_mode` | 角色模式 |
| `role_name` | 角色名 |
| `role_works` | 限定作品 |
| `quality_prefix` | 质量前缀 |
| `artist_on` | 加画师标签 |
| `negative_on` | 输出负面词 |
| `extra_body` | 补充描述 |
| `quality_on` | 加质量前缀 |
| `scene_mode` | 场景模式 |
| `template_override` | 模板覆盖文本 |
| `random_each_run` | 每次运行重抽 |

专有名词保留英文：`JSON`、`danbooru`、档位键 `sfw` / `suggestive` / `explicit` / `hardcore` / `extreme`（下拉项本身带中文说明）。

### 3.4 `IS_CHANGED`

`random_each_run = true`（默认）或 `seed < 0`，且 `template_override` 为空时，返回 `rand:<纳秒>`，保证每次排队都重新执行；否则用全部参数做 SHA1，参数不变则命中缓存。`run()` 里同样会在 `random_each_run` 开启时把 `seed` 强制为 `-1`，所以即使种子被固定成 `>=0`，勾上它也会每次换一份。

## 4. 随机引擎

### 4.1 数据来源

| 文件 | 规模 | 字段 |
| --- | --- | --- |
| `data/tags.json` | 25 分类 / 2956 条 | `en`（英文 tag）、`zh`（中文）、`lv`（0–4）、`meta`（是否评级元标签） |
| `data/scenes.json` | 45 个场景包 | `indoor` / `outdoor` / `water` / `cold` / `night` / `monster` 标记 + 环境/服装/道具/姿势槽位 |
| `data/templates_ui.json` | 1800 套 | `index` / `bundle` / `kind` / `level` / `prompt` |

### 4.2 分级

Lv0 全年龄（2308）→ Lv1 擦边（56）→ Lv2 成人（322）→ Lv3 过激（259）→ Lv4 极端（11）。
`level` 参数决定从哪一层往下抽取；`any` 不做上限。

### 4.3 人数与性向分档

- 默认基础主体是 `1girl solo`。
- 抽到多人槽位（`2girls` / `multiple girls`）时自动补多人标签，并把成人向词切到多人分档。
- 模板侧的成人内容按 sfw / explicit / hardcore 三条线各 300 套，另有 monster 900 套。

### 4.4 场景成套与现实逻辑

`scene_mode = 场景成套` 时，环境、服装、道具、光影来自**同一个场景包**，并由 `scenes.py` 做互斥校验：

- 室内包不会出户外背景，反之亦然；
- 水域包才允许泳装/水中动作；
- 寒冷包不会出泳衣、短袖；
- 夜景包才允许夜景光影词；
- 异性 / 异种只在 monster 线出现。

`scene_mode = 自由随机` 则各槽位独立抽取，组合数量更大，但可能自相矛盾——这是刻意保留的"更多组合"模式。

### 4.5 覆盖优先级

`template_override` 非空时：直接把它当正向提示词使用，不再跑随机；负向词与 level 仍按参数生成。
工作台里的「勾选即写回」就是往这个字段写；取消勾选会同步从文本里删掉。

## 5. HTTP 路由

节点加载时通过 `PromptServer.instance.routes.get` 注册，前缀 `/prompt_forge/`，全部只读：

| 路由 | 返回 |
| --- | --- |
| `GET /prompt_forge/library` | `{cats:[{id,name,icon,tags:[{en,zh,lv,meta}]}]}`，全量 25 分类 / 2956 条，不做档位过滤 |
| `GET /prompt_forge/templates` | `{items:[{id,index,bundle,kind,level,prompt}]}`，1800 套 |
| `GET /prompt_forge/scene_meta` | 45 个场景包的 `indoor/outdoor/water/cold/night/monster` 布尔标记 |
| `GET /prompt_forge/roll?level=sfw` | 现场随机一份 `{positive, negative, level}` |

词库与场景元数据首次请求后缓存在模块级 `_UI_CACHE`。

## 6. 前端工作台（v0.11.17 这一版）

### 6.1 加载方式

- `WEB_DIRECTORY = "./web"`，浏览器按 `/extensions/Comfyui-Prompt-Forge/<文件名>.js` 加载。
- `prompt_forge_v5.js` 只做两件事：`app.registerExtension` 注册 `PromptForge.WorkbenchV5`，在 `PromptForgeRandom` 的 `onNodeCreated` 上追加按钮 `⚙ 打开工作台 v5`。
- `prompt_forge_core_v5.js` 是纯 UI 模块：不 import `app`/`api`，只通过 `globalThis.__pfFetch` 或原生 `fetch` 取数据，因此可以在 `preview.html` 里单独跑。
- `import "../../scripts/app.js"` 的路径是相对 `web` 根解析的；把脚本放进 `web/js/` 子目录会被解析成 `/extensions/scripts/app.js` 而 404，整个扩展失效——这是历史踩过的坑。

### 6.2 面板结构

```
┌ 头部：⚙ Prompt Forge ｜ 🎛 自由选词 ｜ 🗂 模板卡片 ｜ 搜索 ｜ ✕ ┐
├ 左：分类单列（自由选词）/ 场景分类（模板卡片）         ├ 右：已选词条 ┤
├ 主区：标签胶囊 / 模板卡片网格                          │ 输出框      │
└───────────────────────────────────────────────┴ 写回按钮 ┘
```

### 6.3 自由选词页

- 左侧固定三行：`全部`（2956）、`★ 收藏`、`◷ 最近`；分隔线后按 `tags.json` **原始顺序**列出 25 个分类与条数。
- 主区按分类分段平铺胶囊块：英文 + `（中文）`；选中态为绿色描边 + 勾。
- 顶部 `☑ 中文对照` 开关，状态存 `pf_zh_v1`。
- **不做档位屏蔽**：没有 Lv 折叠、没有 level 过滤，任何一条都能点。
- 勾选写入 `template_override`，取消勾选同步删除；点选只重绘该胶囊的状态，不重建 3000 个节点。
- ☆ 收藏存 `pf_fav_tags_v1`；点过的词进 `pf_recent_tags_v1`（最多 20 条）。
- 搜索同时匹配英文与中文；切到某个分类后只在该分类内搜。

### 6.4 模板卡片页

- 左侧场景分类：全部 / 室内 / 室外 / 夜景 / 寒冷 / 水域 / 异种（读 `scene_meta`）。
- 卡片三段：
  1. `#编号` + 场景中文名 + 档位徽章（`sfw` / `explicit` / `hardcore`，异种为紫标）+ 收藏 ☆；
  2. `普通|异种` · `1girl solo|2girls duo` · `N 标签` · 场景名；
  3. `▸ 展开 N 个标签` —— **默认折叠**，点开才平铺标签，再点收起。
- 底部 `复制` / `套用到节点`；套用会整体替换已选词条并复制到剪贴板。
- 每页 9 条（3×3），1800 套共 200 页；支持只看收藏（`pf_fav_templates_v1`）。
- 顶部类型筛选：全部 / 普通 / 异种。

### 6.5 本地存储键汇总

| 键 | 内容 |
| --- | --- |
| `pf_fav_tags_v1` | 收藏词条数组 |
| `pf_fav_templates_v1` | 收藏模板 id 数组 |
| `pf_recent_tags_v1` | 最近点过的 20 条词 |
| `pf_zh_v1` | 中文对照开关 |

### 6.6 独立预览

```
http://127.0.0.1:8188/extensions/Comfyui-Prompt-Forge/preview.html?tab=free
http://127.0.0.1:8188/extensions/Comfyui-Prompt-Forge/preview.html?tab=tpl
```

预览页用一个假节点（只有 `template_override` 空值）打开工作台，能点、能搜、能收藏，但不会写回真实节点。

## 7. 这一版（v0.11.17）改了什么

本版在 v0.11.16 的工作台形态上，补了两件节点侧的事：

1. **新增 `random_each_run`（每次运行重抽，默认开）**：勾上后忽略固定种子，`IS_CHANGED` 直接返回随机戳、`run()` 里把 seed 强制为 -1，所以同一条工作流反复排队，每跑一次都是新的一份提示词。
2. **节点控件全部中文化**：画布上显示 档位 / 随机种子 / 标签上限 / 基础概率 / 槽位权重（JSON）/ 角色模式 / 角色名 / 限定作品 / 质量前缀 / 加画师标签 / 输出负面词 / 补充描述 / 加质量前缀 / 场景模式 / 模板覆盖文本 / 每次运行重抽。
   - 只改显示标签（`widget.label`），序列化键名保持英文，旧工作流和 API 调用不受影响。
   - 专有名词保留英文：`JSON`、`danbooru`、`sfw` / `suggestive` / `explicit` / `hardcore` / `extreme` 档位键（下拉项本身已带中文说明）。
3. 节点显示名改为 `Prompt Forge 随机提示词（中文）`，按钮为 `⚙ 打开提示词工作台`；脚本更名为 `prompt_forge_v6.js` / `prompt_forge_core_v6.js` 以规避浏览器缓存。

## 8. 已知限制

| 限制 | 说明 |
| --- | --- |
| 收藏/最近存 localStorage | 换浏览器、清缓存会丢；未做服务端持久化 |
| 词条无权重 | 目前只有选/不选，不能给单条词加 `(word:1.2)` |
| 面板是网页弹层 | 不是 ComfyUI 节点内嵌控件，靠按钮打开 |
| `template_override` 直通 | 非空即完全跳过随机，不会与随机结果混合 |
| 数据静态 | 词库/模板更新必须 `git pull` 后重启 |
| 未提供 Release | 仓库只有源码，安装必须 git |

## 9. 自检与数据校验

仓库当前不带测试脚本；历史开发目录里跑过的校验（未随仓库分发）包括：

- 模板完整性：1800 套、每条含主体/场景/质量三部分；
- 场景互斥：冬天不出泳衣、室内不出户外背景、水域才出泳装；
- 自由模式：2956 条词都能抽到且不报错。

如需在仓库内复现，建议补 `tests/` 后再写入本节。
